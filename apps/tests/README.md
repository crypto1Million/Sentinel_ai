# Sentinel AI Test Suite

The Sentinel AI test suite validates the system before production deployment.

The test suite covers:

- Unit testing
- Integration testing
- Load testing
- Stress testing
- Performance profiling
- Trading execution
- Rug Radar
- Sentinel Score
- Narrative detection
- AI analysis
- Workers
- Scheduler
- PostgreSQL
- Redis
- Neo4j
- WebSockets
- API endpoints
- Security
